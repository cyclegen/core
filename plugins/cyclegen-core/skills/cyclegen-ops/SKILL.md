# CycleGen Operations（ツール固有操作）

> ツール依存のコマンド名・パスはここに隔離する（ツールごとに差し替え）。
> プロトコル本体は Skill `cyclegen-cycle`、記憶運用は `cyclegen-memory` を参照。

## コンテキストリセットの実行
リセットのコマンドはツール依存: Claude Code は **`/clear`**、他ツールは各相当（例: Codex は新規セッション開始）。

### リセット後の復元手順
1. リセットを実行 → 会話履歴がゼロに
2. 常時規律は hook（UserPromptSubmit毎ターン）＋薄い指示ファイル本文で再注入される
3. 利用者が新しいCYCLEの意図を伝える
4. `memory_search` で関連記憶を再注入（MCP接続時）

### リセットしても消えないもの
- スキル・記憶ストア（MCPサーバーに保存済み）
- プラグインの Skill / hooks（再ロードされる）

### リセットで消えるもの
- 会話履歴（これが目的）

## プロジェクト状態の更新
CYCLE完了時に利用者プロジェクトの状態セクション（薄いCLAUDE.md/AGENTS.md末尾）を更新:
- 現在のCYCLE / 最終更新日 / 今何が揃っているか / 次のアクション / 直近の活動（最新3-5件）

※ PostToolUse hook（`remind-profile-update.sh`）でリマインドされるが、hook無効ツールでも必ず更新する。

## 記憶ストアが動かないときに何をするか（CYCLE20.7）

> **平常時の案内はそろっているのに、いちばん困る場面にだけ何も無い**——という状態を埋める節。
> 記憶ストア（MCPサーバー）は、**型（スキル）や規律（hook）とは別に、単独で落ちることがある**。
> 落ちても他は動き続けるので、**一見すると正常に見える**。

### まず、状態を確かめる（利用者は自分では確かめられない）
利用者の画面には「MCPツールが何本つながっているか」を数える場所が**無い**（F-16／M-17）。
確かめる手段は実質、**AIに聞くこと**しかない。だから聞かれたら次のように答える:

1. `memory_status` を実際に呼ぶ。**返ってくれば生きている。**
2. 返らない・エラーになる・そもそもツール一覧に `memory_*` が無い → **止まっている。**
3. ★**ツール一覧を目で数えた結果を「接続の証明」として答えない。** 一覧に出ていることと、
   呼べることは別（CYCLE17.6.4 で実際に食いちがった）。**呼んで確かめた結果だけを報告する。**

### 止まっていたときに案内する手順（この順に、これだけ）
1. **AIクライアントを「終了」する。** ★ウィンドウの × で閉じるだけでは終了しない。
   - Windows: 画面右下の「^」からアイコンを右クリック →「終了」
   - macOS: メニューバーのアプリ名 →「終了」（Cmd+Q）
2. **起動し直す。**
3. それでも戻らないとき: ホームフォルダの `.claude` にある `mcp-needs-auth-cache.json` を
   削除して、もう一度起動する（Windows: `%USERPROFILE%\.claude\` ／ macOS: `~/.claude/`）。
   AIクライアントが CycleGen のサーバーを「認証が必要」と誤って記録することがあり、
   その記録が残っているあいだは何度起動し直しても起動されない。消して問題ないファイル。

### ★やらないこと
- **ターミナルで `uvx` を叩いて起動テストする／MCP設定ファイルを読んで原因を特定する、といった
  開発者向けの手順を提案しない。** CycleGenの利用者はターミナルを開かない前提で設計されている。
  モデルにとって自然な復旧策はターミナルと設定ファイルなので、**意識して外す**。
- **こちらから `mcp-needs-auth-cache.json` を勝手に消さない。** AIクライアントが自分で管理して
  いるファイルなので、削除するかどうかは利用者が決める。手順として案内するところまで。

### 待っているのか、壊れているのか
初回の記憶ツール呼び出しは、埋め込みモデル（約240MB）の取得で**1〜2分かかることがある**。
**これは故障ではない。** 呼ぶ前に「初回は1〜2分ほどかかることがあります」と先に伝える
（詳細は Skill `cyclegen-memory`）。予告せずに黙って待たせると、利用者は故障と区別できない。

## CycleGen Finish（md→docx変換・条件付き有効化）
CycleGen Core同梱の変換スクリプトがある場合のみ:
```
python3 <CYCLEGEN_CORE>/scripts/finish/cyclegen_finish.py <input.md> --template <template>
```
テンプレート: executive, minimal, creative, modern, wa-modern, gold, paperback, green

> **思考モードのプロンプトサジェスト（旧O2）はここに置かない。** prompts skillは廃止（CYCLE14.5 F3-a）。サジェスト機能は明示コマンド `/cyclegen mode <x>`（F4で実装）へ移管する。正本のサジェスト表は `~/.claude/CLAUDE.md` プロンプトサジェスト節＋`docs/design/CYCLE12.9.2_cyclegen-ops改訂案.md` に残る。
